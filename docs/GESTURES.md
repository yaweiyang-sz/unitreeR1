# 手势 ↔ 动作 完整指南 (v2)

## 速查表

| 手势 | 名称 | 机器人动作 | 触发条件 |
|------|------|-----------|---------|
| ✋ 张开手掌 + 不动 | **STOP** | 停下 | 5 指全张, 手腕不挥动 |
| ✋ 张开手掌 + 向左挥 | **LEFT** | 左转 | 5 指全张, 手腕水平速度 < -150 px/s |
| ✋ 张开手掌 + 向右挥 | **RIGHT** | 右转 | 5 指全张, 手腕水平速度 > +150 px/s |
| ☝️ 食指单独竖起 | **FORWARD** | 前进 | 只有食指伸出 |
| ✊ 拳头 | **BACKWARD** | 后退 | 5 指全弯 |
| ✋ 张开 1.5 秒 | **进入跟随** | 自动锁定你 | STOP 持续 1.5s |
| ✊ 握拳 0.5 秒 | **退出跟随** | 回到手势控制 | BACKWARD 持续 0.5s |
| 按 `q` / `ESC` | **急停 + 退出** | 立即停 | 任意时刻 |

> 上面这套在画面**右上角**永久显示。

---

## 重大变更（v2 方案）

之前的"👈 拇指伸出 = 左转"对手心朝向太敏感，识别率很差。**v2 改成自然得多的方案**：

- **张开手掌** = 激活态 (Active)
- **挥动方向** = 转向方向
- **保持不动** = 停止

这意味着：
- ✅ 不需要手心朝镜头（任何朝向都行）
- ✅ 不会因为握拳/伸拇指/伸小指混淆
- ✅ 用户体验更自然（挥手的方向就是机器人转向的方向）

---

## 每个动作的判定标准

### ✋ STOP
- 5 个手指全伸直 (所有 ratio > 阈值)
- 手腕水平速度 |vx| < 150 px/s
- 实际上：把手张开，**保持不动** 0.3 秒

### ✋← LEFT
- 5 个手指全伸直
- 手腕水平速度 vx < **-150 px/s**（向左挥）
- 持续挥动期间一直输出 LEFT

### ✋→ RIGHT
- 5 个手指全伸直
- 手腕水平速度 vx > **+150 px/s**（向右挥）
- 持续挥动期间一直输出 RIGHT

### ☝️ FORWARD
- **只有食指**伸出（其他手指弯曲）
- 不管手腕怎么动，FORWARD 都会覆盖 STOP/LEFT/RIGHT

### ✊ BACKWARD
- 5 个手指全弯（握拳）
- 不管手腕怎么动，BACKWARD 都会覆盖
- ⚠️ 持续 0.5 秒 → 退出跟随模式

## 界面调试面板

左下角的实时状态条能看到：

```
拇 [▓▓▓▓░░░░] 1.49   ← 绿色=伸直, 红色=弯曲
食 [▓▓▓▓▓▓░░] 2.33
中 [▓▓▓▓▓▓░░] 2.21
无 [▓▓▓▓▓▓░░] 2.33
小 [▓▓▓▓▓▓▓░] 2.55
手速 [▓▓▓▓→]  +300   ← 蓝=向左, 橙=向右, 灰=静止
```

**手速行含义**：
- 数字：手腕水平速度 (px/s)，正=向右，负=向左
- 颜色：
  - 🟧 橙色 = 向右（> +150）
  - 🟦 蓝色 = 向左（< -150）
  - ⬜ 灰色 = 静止（|vx| < 150）

## 调试 LEFT/RIGHT 触发

### 挥动速度调阈值
如果发现**挥动很快**才能触发方向，阈值太高；在 `src/vision/hand_gesture.py` 改：

```python
def __init__(self, ..., motion_speed_thresh: float = 150, ...):
    # 把 150 改成更小的值 (比如 100) 让挥手更灵敏
    # 改成 200 让挥手需要更快才触发
```

### 挥动还是不出 LEFT/RIGHT
看左下角"手速"那一行的实时数字：
- 静止时：`|vx| < 50`，颜色灰
- 慢速挥动：`|vx| ~100`，颜色可能还是灰
- 快速挥动：`|vx| > 200`，颜色应该变成蓝/橙
- 如果快速挥动时数字**没上去**：MediaPipe 手腕关键点识别不稳，建议**把整只手在画面里**挥动，不只是手指

### STOP 误触发
如果你不动手，状态条一直显示 STOP，机器人就停。挥动一下就触发方向。

### FORWARD 不出来
- 看食指 ratio：伸直时 > 1.65
- 看其他手指 ratio：弯曲时 < 1.0
- 常见问题：食指伸出时拇指也跟着被判 True（拇指伸出 < 1.3 阈值）
- 解决：调高拇指阈值到 1.5（在 `hand_gesture.py`）

## 站位说明

默认你站在机器人**后方**（和机器人朝向一致）：
- 你的"前方" = 机器人前进方向
- 你的"左" = 机器人左转
- 你的"右" = 机器人右转

如果你要**面对**机器人发手势，转向是反的。改 `config.yaml`：
```yaml
control:
  turn_direction_sign: -1  # 翻转方向
```

## 跟随模式

1. 站到机器人前方 1.5~2 米
2. ✋ 张开手掌（不动）持续 1.5 秒 → 状态从 `GESTURE` 变 `FOLLOW`
3. 机器人自动朝你走来，保持约 2 米距离
4. ✊ 握拳 0.5 秒 → 退出跟随

⚠️ **注意**：握拳**也会触发 BACKWARD（后退）**，所以在跟随模式里握拳会同时做"后退"和"退出跟随"两件事。如果你只想退出不想后退，可以在 `config.yaml` 调高 `control.gesture_to_follow_hold_sec` 阈值，或者在 `gesture_to_command.py` 里把 BACKWARD 跟随时段的速度改为 0。
